# Blue Rose · 碎冰蓝粒子玫瑰

这是一个有茎、有叶的完整 3D 粒子玫瑰视觉原型。运行及操作见[仓库 README](../README.md)，设计路线见[公开规格](../docs/BLUE_ROSE_SPEC.md)。

## 当前功能

- 27 片参数化花瓣，分为 6 层，具有不完全对称的曲率、卷边与厚度。
- 蓝色花茎、花托和三片叶子。
- 初绽、半开、盛开三个静态状态。
- 旋转、缩放、固定视角、粒子材质近景。
- 稀疏远星、弱空间雾、花瓣流光、持续逸散碎屑。
- 暂停与恢复动态，响应系统减少动态效果偏好。

## 代码导航

全部实现在 `index.html`：

- `layers / petals / petalSurface`：花瓣结构与开放形态。
- `botanicalSurfaces`：茎叶及花托。
- `makeRose / makeConnections`：主体粒子与暗部连接面。
- `roseVertex / grainFragment / connectionFragment`：粒子、逸散与花瓣着色。
- `backdropFragment`：背景星点及雾层。
- `setBloom / render`：形态更新与渲染。
- `zoomBy / turnBy`：观察操作。
- `artworkTime / motionPaused`：动态时钟和暂停。

## 开发约束

当前共 63,610 个粒子，索引使用 Uint16；增加总量时不能超过现有索引容量，必要时迁移为 Uint32 或拆批。深度排序使用主体采样位置，逸散粒子的动画位置并未单独重新排序，后续可评估透明叠加误差。

开合参数映射到 0.53–0.76，这只是当前视觉范围，不是最终验收标准。当前 `setBloom` 会生成并上传几何，不能直接以高频调用冒充经过性能验证的连续开合。

粒子碎屑是附加的日常逸散，主体粒子仍保持原结构；它不是整体崩散功能。
