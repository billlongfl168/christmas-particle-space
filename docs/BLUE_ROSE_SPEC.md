# 蓝玫瑰与粒子艺术：公开开发规格

## 艺术方向

以完整的一枝玫瑰为中心，包含花冠、自然弯曲的茎、花托和错落叶片，全部使用低饱和碎冰蓝。粒子为主体，允许少量暗部连接面支撑深度；不能成为实体表面撒亮粉的效果。

背景接近黑色的深蓝灰，只保留极弱空间雾和稀疏远星。暗部与留白充足，主体始终比背景清晰。避免紫蓝霓虹、密集星云、镜头光斑及持续闪烁。

## 花型与材质

中心紧密、有轻微旋转趋势；花瓣内紧外宽、层层错开，具有曲率、卷边、遮挡与适度不对称。正面、斜侧、侧面均可辨识玫瑰，不能以球形点云或同心波纹替代。

粒子覆盖花瓣内部及边缘，层间保留空隙。采用深蓝暗纹、明暗和密度塑造层次，避免通过大光晕糊成花形。单颗粒子需要方向高光、球面明暗与薄边缘光晕，不要求夸张放大。

当前视觉仍待打磨与验收。重点改善花瓣可读性、硬亮粉感、背景细腻程度及主体空间融合。

## 三类运动

- 开合：从微开偏半开到克制盛开，外层先舒展，内层随后，保持包裹感；变化来自角度、曲率、卷边与层间距离，不是整体缩放。
- 日常逸散：少量细碎粒子缓慢离开边缘并淡去，主体始终完整。
- 整体崩散：同一批主体粒子向横向、纵向、纵深扩散，最大时原轮廓消失；回聚恢复原花型和原开合程度。

开合、崩散均应连续可控，可在任意程度停住并随时反向。采样身份稳定，避免每帧重新随机造成闪烁。

## 手势计划

| 动作 | 输入 | 排他规则 |
| --- | --- | --- |
| 切场景 | 稳定食指指向加左右划动 | 位移阈值、冷却、重新触发，每次一个场景 |
| 开合 | 单手自然握拢与张开 | 按手尺寸归一化，平滑与死区 |
| 旋转 | 单手捏合拖动 | 不同时改变开合 |
| 崩散 | 双手稳定捏合后拉开或靠拢 | 最高优先级，暂停开合与切换 |
| 缩放 | 滚轮、触屏双指 | 不复用单手张合手势 |

丢手保持状态，恢复后重建基准。提供非摄像头替代控制。一次调整一个灵敏度参数，记录误触、漏识别、延迟和稳定性，区分模拟输入与真人测试。

## 后续场景

立体爱心采用低饱和冷玫瑰色或淡银粉，具有真实厚度、曲率和前后层次，轻微呼吸。

太阳采用低饱和香槟金、灰金和少量暖白，有可辨球面、表面流动与局部薄日冕，不过曝成白盘，不使用等间距放射线。

场景切换保持背景和空间尺度，以粒子解构、重组完成，避免白闪与突然换图。过渡期间明确冻结和恢复交互模式。

## 验收顺序

1. 静态花型、近景材质与多视角视觉。
2. 普通控件连续开合与可逆崩散。
3. 摄像头手势及模式仲裁。
4. 爱心、太阳、场景过渡。
5. 移动端、性能、可访问性与错误恢复。

不以增加粒子数量代替几何和材质改进。依据设备实测调整密度、分辨率和后处理。参考影像仅用来观察效果，不推断原作者技术；未获再分发许可的录屏不随代码发布。
